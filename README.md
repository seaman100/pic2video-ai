# Pic2Video AI

Turn a still image into a short video clip, entirely in the browser.

The tool itself is at [AI video templates](https://pic2videoai.com/templates).

There is a longer walkthrough at [turn a product photo into a TikTok clip](https://pic2videoai.com/tiktok-ai-video-generator).

Project home: [Pic2Video AI](https://pic2videoai.com/).

---

Independent project. Free to use in the browser, no account required.
